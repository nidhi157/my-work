Creating Popup in JavaScript

JavaScript allows developers to create interactive web pages. One of the most common examples is a popup advertisement or notification box. A popup can automatically appear after a few seconds using the setTimeout() function. It is useful for displaying offers, important announcements, welcome messages, or product advertisements. In this example, the popup appears automatically after five seconds, shows an image and title, and can be closed either by clicking the close button or automatically after ten seconds. This demonstrates how JavaScript can dynamically create and remove HTML elements from a web page.

The popup created in this program is generated dynamically using document.createElement(). The popup is inserted into the page with appendChild() and removed using removeChild(). The close button lets the user dismiss the popup manually, while the automatic timer removes it after ten seconds. This example is commonly used in websites for promotional offers, welcome messages, product advertisements, and important notifications. It is a simple and effective demonstration of DOM manipulation using JavaScript.
